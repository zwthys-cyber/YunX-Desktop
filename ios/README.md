## 操作约束

按仓库使用者最新授权，当前代理服务器可读取、编辑和推送源码，但不编译、不运行测试或验证脚本；编译、自动测试及打包只在 GitHub Actions 执行。iOS 构建使用 GitHub 托管 macOS runner，不创建会触发上游 Windows 构建的 PR。也保留用户自行在本地 Mac 构建的方式。

## AcFun 与 HLS（离线测试已通过，待平台和真机）

新增 AcFun 标准 `ac` 作品链接、嵌套播放 JSON 和平台返回的各 HLS 档位。HLS 不通过直链下载器保存播放列表，而是交给原生引擎解析、分片和合并；输出名使用引擎实际计划的 TS/fMP4 等容器，任务在「下载 → 引擎任务」查看。此路径不接受账号 Cookie/Authorization。已编写 HLS 在线预览：仅监听 127.0.0.1 的随机端口并使用随机 token，重写播放列表/分片/密钥/初始化段路径，HTTPS 上游使用安全媒体请求头，不转发账号凭证，流式传输并随播放器关闭。只为本地网络设置 ATS 例外，不全局开放明文。受 DRM 保护的播放流程不在此路径处理。仍需云端回环代理测试和真机播放验收；多分 P AcFun 和 TS 转 MP4 尚未完成；不将 m3u8 冒充 MP4，不宣称完整媒体功能已经验收。

引擎冷构建会在 GitHub 执行上游基于本机测试 HTTP 服务的 HLS 端到端测试，覆盖 Referer、AES-128 换钥、ByteRange、暂停与持久化恢复，不访问实际视频平台。iOS 的对应运行与设备性能仍需验证。

## B 站 DASH 与原生合轨（开发中，待当前云端检查）

登录后可优先请求平台 DASH 音视频，按实际返回的画质选择 H.264/HEVC 视频和 AAC 音频；同档优先 H.264，不虚报请求画质。分轨不足时带提示回退单文件的全部片段。在线预览仅使用额外取得的完整单文件流，画质可能不同；没有该流时提示下载后播放。

## 原生 P2P 引擎（云端构建及本地种子解析已通过，待真实网络和真机）

「我的 → P2P 下载引擎」接入固定源码版本的 Gopeed，支持磁力、ed2k、导入种子、任务暂停/继续/删除记录、完成文件导出、Tracker 和 DHT 配置。不是桌面 EXE 或远端服务器代理：GitHub macOS runner 使用 gomobile 构建 arm64 设备与 arm64 模拟器 XCFramework，静态链接到应用，默认不开放 HTTP 管理端口。引擎有独立持久化目录，完成文件位于 Documents/P2P，每个任务单独目录。删除记录保留文件。

DHT 默认关闭，手动开启后需重启应用重建连接；Tracker 不自动从第三方订阅。前台运行不代表长期后台可用；已编写 Peer/做种概览（按引擎实际字段展示，不虚构节点数），尚需云端及设备网络/恢复验证。CI 只解析生成的本地测试种子，不连接真实下载资源。构建同时上传固定版本及修改后的引擎对应源码，最终分发需保留对应源码及 GPL-3.0 声明。

本地 Mac 若自行编译，还需 Go 1.26+，先执行 `bash build-engine.sh`；服务器仍不执行此步骤。GitHub 首次原生引擎冷构建可能较慢，后续使用按源码和 Xcode 版本隔离的框架缓存。

## 诊断（开发中，待云端检查）

「我的 → 诊断」记录固定启动、引擎、下载和合轨事件，仅接受枚举事件名、时间及数字字段；不接受请求 URL、文件名、账号、请求头或原始异常字符串。日志最多 3×256 KB，导出时按类型重新编码，额外字段丢弃；仅保留一份导出文件，可一键清除。原始 Gopeed 日志不随此功能导出。

普通任务可查看接收大小、预期大小及会话方式；原生任务可查看引擎真实返回的 HTTP 连接、重试次数与平均份额进度，或 P2P Peer/做种统计，不伪造固定分片区间。

## 系统后台下载（已编写，待云端和设备验收）

公开 HTTPS 文件使用固定标识的系统后台 URLSession；任务 UUID 与受保护索引关联，应用启动和系统后台唤醒都重新建立同一会话并查询原任务，不重复创建已有任务。完成回调先处理文件及记录，再在主队列通知系统事件处理结束。先前主动暂停的任务不会因重新关联而自动继续；未知/删除记录的遗留系统任务取消。索引与断点文件采用首次解锁后可用的系统文件保护，支持锁屏后的正常回写。

后台会话会自动跟随重定向且不调用应用的重定向检查，因此 Cookie、Authorization、代理鉴权或自定义鉴权头请求保留在前台；仅允许无鉴权或 UA/Referer/Origin/Accept 头的 HTTPS 请求进入后台。GitHub 私有 API 下载也使用前台策略。原生 P2P/HLS/DASH 引擎不因该功能获得常驻权限。系统可延迟任务，用户强制退出后的行为与真实锁屏、终止恢复均待设备验收；不能用模拟器策略测试代替后台验收。依据：[Apple 后台传输文档](https://developer.apple.com/documentation/foundation/downloading-files-in-the-background)。

已补充任务索引保护，待云端检查：启动时记录无法读取则保留原文件并停止覆盖；新增、删除、继续或全部继续无法持久化时回退列表状态，不启动未保存任务。此保护不替代备份、完整数据库迁移或设备存储故障验收。

「我的 → 设置与收藏」可切换跟随系统/浅色/深色，管理最近 200 条历史及不限历史条数的收藏。网盘、媒体和 GitHub 输入页可从历史重新填入。网盘记录包含分享提取码，使用本应用受保护文件存储；不记录账号 Cookie/Token。清空历史保留收藏，删除收藏需单独删除。API 解析失败的有效格式链接也会保留为输入历史，不表示解析成功。

个人文件下载会通过官网生成分享链接，界面在此操作前单独确认，禁止后台批量默默生成分享。下载节点支持 down_ip、公开字符串变换挑战 Cookie 及官网「验证并下载」确认；真正的人机验证或不支持的页面明确失败，不保存成文件。个人盘支持新建、重命名、文件移动及删除；官方源实现不支持文件夹移动及分享直接转存，界面会显示对应限制。当前链接、验证页和会话流程仍待真实平台、目标设备及云端测试。

## 内置网页资源浏览器（开发中，待云端及设备验证）

「我的 → 网页资源浏览器」提供独立非持久会话，可手动访问 HTTPS 页面、前进/后退、读取已加载 DOM 与 Resource Timing 中的可下载链接，按图片/视频/音频/文档/压缩包/安装包/字体筛选。最多显示 200 项并报告省略项，提供预览、显式下载和系统分享；当前浏览器遇到附件响应会先询问是否交给下载队列。HLS 的 m3u8 使用原生引擎，普通文件进入现有队列。读取前后核对页面，导航过程中变化则丢弃结果。

不扫描其他应用、不读 Cookie、不自动取消 Safari 下载；iOS 无法直接移植 Chrome downloads 接管 API。此浏览器只列出已加载且可见于 DOM/资源时间线的数据，不承诺发现 blob、DRM、服务工作线程内部或未加载资源。下载使用净化后的页面来源和 UA，不带浏览器认证状态；鉴权资源应使用对应平台解析。Safari 分享扩展仍待完成。

## Safari / 系统分享入口（开发中，待云端和设备权限验证）

新增「保存到云析」原生分享扩展，接收系统提供的 URL/文字，不读取其他应用的浏览器数据库或账号。内容写入共同 App Group 中的受文件保护收件箱，跨进程文件锁控制最多 100 条、单条 UTF-8 32KB；写入失败不会显示成功。扩展不发网络请求，不尝试绕过系统限制强行唤起主应用。保存后打开「我的 → 分享收件箱」，可填入对应的网盘、媒体、GitHub、P2P 或文件下载输入框，再由用户确认操作。记录保留到用户删除。

GitHub 构建将同时构建、嵌入并分别签名扩展与主应用，检查两个 arm64 可执行文件。尚未验证 TrollStore 在目标设备授予共同 App Group 的实际行为，也未完成 Safari 分享面板验收；共享容器不可用时会明确报错，仍可复制链接在主应用粘贴。种子文件继续使用主应用的「导入 .torrent」文件选择器，此扩展只接收链接和文字。

## 同一视频分 P 的片段拼接（开发中，待云端与设备验证）

B 站单文件模式返回多个 durl 片段时，可分别下载，也可选择「按顺序下载并拼接片段」。每个源片段使用现有原生下载引擎，可暂停、持久化并在重启后手动继续，完成后由 iOS AVFoundation 依原顺序无损导出一个 MP4。新计划与旧 DASH 合轨记录保持解码兼容，记录保存失败不启动未登记任务。

拼接检查视频轨道、尺寸、编码、方向和音频一致性，导出后再次检查可播放性、音频及总时长；不兼容时保留原片段并提示失败，拒绝覆盖既有输出。准备使用真实 H.264/AAC 样本在云端核对连续片段的总时长、视频样本数及音频保留。Pixiv ugoira 与小说按桌面源版本的明确范围继续不支持，不将 ZIP 伪装为图片。
