## 执行约束

- 服务器只读取、编辑和推送代码；不编译，不运行测试、模拟器或验证脚本。
- 编译、自动测试及 IPA 打包使用本仓库 GitHub 托管 macOS Actions。
- 完整交付还需要目标设备安装及真实账号/平台验证。测试不绕过平台授权、付费、会员或风控要求。
- Windows 专用实现采用 iOS 对应能力。不能等价实现的能力必须列出平台限制及实际替代行为，不能直接勾选完成。

## 下载链路仍需补齐的具体差距

- 全局带宽限制必须同时约束系统会话和原生 HTTP 引擎；原生 HTTP 文件的共享、可取消速率预算已通过 180 项回归中的实际传输用例及 Go 并发测试，普通 URLSession/HLS/P2P 尚不覆盖。仅降低任务优先级或延迟进度刷新不能算限速实现。
- 分片级 SHA-256 校验与整文件 SHA-256 是两项能力。新增原生 HTTPS 文件按实际写入增量累计不超过 1 MiB 的段摘要，与断点进度共同持久化；恢复请求前及完成前重读各段并检查覆盖范围，损坏/缺失摘要不得完成或复用，临时 I/O 失败保留原文件。设置每任务摘要数量与活动流预算，超限停止。原生写入、预读交接、Range 暂停换链、磁盘篡改及实际 iOS 下载已通过 `4870fec` 的对应云端检查；系统会话、HLS、P2P 和旧任务仍不覆盖，不能据此称所有下载方式已完成分片校验。
- 十个网盘平台的独立连接数及原生下载入口已通过云端编译及打包；视频合轨/片段/动态照片源的按平台连接设置、任务快照及高连接数确认已通过 `8991483` 的完整云端检查。GitHub 文件/Release/源码 ZIP 的原生选项与独立连接数、格式核对和点文件导出，已通过云端检查；原生模式官方源、系统模式保留镜像/后台策略。普通视频单文件原生模式已通过云端检查。原生 HTTP/2、读缓冲、慢连接策略及真实 Range 换链已通过完整云端检查；系统会话及其他下载方式不继承这些设置。
- 新增网盘原生任务的来源上下文、原账号身份/当前有效凭证检查、目录及文件令牌重读、用户明确确认后的手动取链重建；分享提取码与令牌只放 Keychain，原生记录仅存上下文 ID。人工确认下的续传仅对停止后的部分数据、相同大小及已固定强 ETag 生效；原上下文版本比较、物理停止、请求头替换、旧 If-Range 约束和真实带鉴权 Range 换链用例已通过 `8991483` 的完整云端检查。尚未实现系统会话/旧任务的来源迁移和自动触发刷新；条件不足时从头新建，不混用旧片段，不暗中转存。用户明确转存到个人目录的文件不得自动删除。
- 下载完成文件的校验、跨卷复制已改为可取消的工作任务；私有目录保留完整下载，目标文件发布前写恢复记录，目标文件大小与 SHA-256 通过后才提交完成状态；取消、同名保护、发布后恢复、缓存缺失后的再次启动和无网络继续保存用例已通过 `8991483` 的完整云端检查。仍需外部文件提供器及真机中断验收，目录迁移测试不能替代此项。
