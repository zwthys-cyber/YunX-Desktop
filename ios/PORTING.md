# iOS 完整移植验收表

本表以 `../docs/FEATURES.md` 为功能来源。用户要求全部完成后交付；开发分支提交、模拟接口测试通过和 IPA 打包成功均不等于最终交付。未完成项目不得以隐藏按钮、仅保存凭证、只打开外部网页或不可运行的引擎占位代替。

## 执行约束

- 服务器只读取、编辑和推送代码；不编译，不运行测试、模拟器或验证脚本。
- 编译、自动测试及 IPA 打包使用本仓库 GitHub 托管 macOS Actions。
- 完整交付还需要目标设备安装及真实账号/平台验证。测试不绕过平台授权、付费、会员或风控要求。
- Windows 专用实现采用 iOS 对应能力。不能等价实现的能力必须列出平台限制及实际替代行为，不能直接勾选完成。
